# Compra Ya Web

Nueva experiencia React para Compra Ya v0.1.0, con navegación mínima, catálogo, página institucional y checkout conectado al API TypeScript.

## Ejecutar

```bash
npm install
npm run dev
```

Por defecto usa `http://localhost:4000`. Para cambiarlo:

```bash
VITE_API_BASE=http://localhost:4000 npm run dev
```

Rutas: `/`, `/empresa` y `/vender`.

El build se genera en `public/react-app`, que es el artefacto preparado para publicar como aplicación principal.
